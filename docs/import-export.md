# 文本导入 / 导出（手机优先）

参考 NT账本：**不依赖文件保存**，所有内容都能在文本框里复制/粘贴。
TxtVein 的差异是：**明文是单文件；密文备份是双文件**，所以密文给两个框。

## 导出

### 明文 · 单文件

一个文本框：

- TxtVein 单 TXT：`## 统计 / ## 流水 / ## 行为 / ## 备注 / ## 字典`
- NT 明文：`账户：` + `流水：` 两段，可直接粘到 NT账本导入框

按钮：生成文本 → 复制明文。

### 密文 · 双文件

两个文本框：

1. 流水密文：`ledger.shadow` / `ledger.enc`
2. 字典密文：`dict.vault` / `dict.enc`

按钮：生成初级密文 / 生成深度密文 → 分别复制。

**加密逻辑始终是 TxtVein 的：**
PBKDF2-SHA-256（150000）→ AES-GCM-256；密文带 `[SECURE_START]` /
`[SECURE_END]` 装甲。NT 的加密格式不参与 TxtVein 的加密。

## 导入

### 明文 · 单文件

一个文本框，识别：

- TxtVein 单 TXT
- NT 明文（`账户：` / `流水：`）

### 密文 · 双文件

两个文本框：

1. 流水密文
2. 字典密文

两个都粘，再输密码。缺少一个会拒绝，不会静默半导入。

兼容读取：

- TxtVein bundle（旧版单段粘贴）
- NT 加密备份（`-----NT账本加密备份-----`，仅作为兼容导入；
  不会成为 TxtVein 的加密格式）

## 互通边界

| 方向 | 状态 |
|---|---|
| TxtVein 明文 → NT账本 | 支持：NT 直接导入 TxtVein 单 TXT |
| NT 明文 → TxtVein | 兼容：仍可粘贴旧 NT `账户 / 流水` |
| TxtVein 密文 → TxtVein | 支持：bundle 单框 + 密码 |
| NT 加密备份 → TxtVein | 兼容导入 |
| TxtVein 密文 → NT账本 | 新版 NT 已接 TxtVein 信封；旧版需更新 |

## 手机流程

1. 导出 → 生成文本 → 复制；
2. 发到微信/备忘录；
3. 另一台设备打开导入 → 长按粘贴（或点「从剪贴板粘贴」）；
4. 密文粘两个框，输密码，导入。
