# 统计口径 · 与 NT账本完全对齐

> 状态：v2.7.0 已实现（统计口径未变）
> 对应 NT 账本：`nt/js/core/ledger-stats.js`（单账户汇总）、
> `nt/js/core/stats-panels.js`（六类 × 四列）、`nt/UI-SPEC.md` §2。
> TxtVein 实现：`js/core/stats.js`；测试：`tests/stats.test.cjs`。

---

## 1. 只做一件事：六类 × 四列

统计页（分类 / 节点）共用同一套数，只差第一列：

| 类型 | 第 1 列 | 第 2 列 | 第 3 列 | 第 4 列 |
|---|---|---|---|---|
| 收入 | 期初累计 | 本期收入（转出） | 本期退回（转入） | 期末累计 |
| 负债 | 期初余额 | 本期新增（转出） | 本期偿还（转入） | 期末余额 |
| 权益 | 期初余额 | 本期增加（转出） | 本期减少（转入） | 期末余额 |
| 资产 | 期初余额 | 本期流入（转入） | 本期流出（转出） | 期末余额 |
| 费用 | **本期累计** | 本期支出（转入） | 本期退回（转出） | **本期净出** |
| 成本 | 期初净值 | 本期新增（转入） | 本期消耗（转出） | 期末净值 |

顺序固定为 **收入 / 负债 / 权益 / 资产 / 费用 / 成本**；有内容才出表。

---

## 2. 数学只有三套

A 极 = 资产 / 费用 / 成本（借增贷减）；B 极 = 收入 / 负债 / 权益。

```text
B 极：期初 = 历史转出 − 历史转入
      本期增 = 本期转出    本期减 = 本期转入
A 极：期初 = 历史转入 − 历史转出
      本期增 = 本期转入    本期减 = 本期转出

第 4 列 = 期初 + 本期增 − 本期减（费用除外）

费用：第 1 列 = (历史转入 + 本期转入) − (历史转出 + 本期转出)
      第 4 列 = 本期转入 − 本期转出      （本期净出，不是期末余额）
```

- **金额永远是正数**：转出 / 转入只由 `from` / `to` 决定方向，
  不存在「负数流水」；第 2 / 3 列是金额之和，必然 ≥ 0。
- **只有余额列可能为负**：负债转入 > 转出 = 多还，显示 `多还 300.0`；
  其余类型的负余额保留负号（NT 同口径）。
- **费用是例外**：第 1 列看「到本期结束」的累计净支出，
  正好等于资产类的期末；第 4 列只报本期净发生额，所以费用没有「期末」。
- **滚动**：`本期累计 = 上期累计 + 本期净出`。

---

## 3. 期初（NT 的表达）

期初不是账户上的一个数字字段，而是**一笔真实流水**：

- 资产 / 费用 / 成本：`期初虚拟账户 → 账户`；
- 负债 / 权益 / 收入：`账户 → 期初虚拟账户`；
- 日期早于所有其他流水（TxtVein 用 `000101`，NT 用最早一笔的前一天）；
- 金额为正，方向决定它落在哪一极。

统计时：

- 期初流水落在区间之前 → 进「历史」→ 第 1 列；
- **期初虚拟账户本身是隐藏账户**，不占统计行；期初只体现在各账户第 1 列。
  NT 的 `isHidden`，TxtVein 的 `system` / `isHiddenAccount` 同义。
- 旧版 NT 导入可能没写 `system`：`isHiddenAccount` 还会按简码
  `nt_open` / `ntg_open` / `legacy_open` / `open` 识别，避免旧账本把
  「期初权益」当成一张真的权益表。

## 4. 聚合规则（分类 / 节点）

- **分类视图**：按节点的 `category_key`（v4 统计分类）聚合；
  多个节点同一分类合成一行；无分类 → `未分类`。
- **节点视图**：每个节点一行。
- 行过滤：四列全 0 的行不出现；整类全 0 的表不出现。
- 类内排序：按第 4 列绝对值降序，再按名称。
- 每类合计：逐列相加（不是另算一套）；合计行放在表头上方。
- **统计只认金额流水**：时间代币、行为边、0 金额不参与。

---

## 5. 显示

- 金额 **1 位小数、不带 ¥、不带千分位**（NT `statAmount` 同款），
  整列小数点对齐。
- 负债负余额写 `多还 1070.0`；其它负余额保留 `-`。
- 表头按类型不同（见 §1），不再用「流入 / 流出」一套标签套所有类型。

---

## 6. 与 NT 的字段 / 单位对照

| NT | TxtVein |
|---|---|
| 元（number） | 分（整数 cents） |
| `YYYY-MM-DD` | `YYMMDD` |
| 账户 `type`：`资产类` 等 | 节点 `type`：`资产` 等（短名） |
| 账户 `category` | 节点 `category_key` + `dict.categories` 名字 |
| `isHidden` | `system` / `isHiddenAccount` |
| `opening: true` 流水 | 日期 `000101` 的期初流水（虚拟账户） |
| `statCells` / `categoryStats` / `nodeStats` | `statCells` / `groupStats` |
| `statAmount` | `statMoney` |
