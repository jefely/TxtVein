## 五、§8–§11 逐条

### §8 多域
- 前台域切换器：[P][F][C][H] + 计数：已实现。
- 落盘显式域标记：已实现（`[P]`）。
- 跨域穿透：显式前缀；报表按域边界抵消；**不做镜像双记**（见偏差 2）。
- 独立/合并视角：部分。独立视角 + `[全] 合并` 视图 + 内部划拨抵消摘要；六类明细表在合并视图仍按毛额展示，未逐类扣内部划拨（避免把「内部转账」误当消费）。

### §9 规则
- 9.1 周期规则：`*d*m*y`、当前流水 + 计划、取消/恢复、last_run：已实现。
- 9.1 规则面板 Ctrl+R：已实现。
- 9.1 删除周期流水时提示「今天 / 取消未来」：部分（删除流水走统一确认；取消未来在规则面板单独做）。
- 9.2 特征池 → 组合锚定 → 用户赋权：部分（标签自动创建 + 事件规则预测；没有「高频组合发现」挖掘 UI）。
- 9.3 事件定义中枢三栏：部分（规则列表 + 预测模板；没有拖拽拼装台）。

### §10 存储
- 10.1 三模式：已实现。
- 10.2 哈希互锁：已实现；「字典解密时自动锁定」做成错误提示 + 拒绝导入，不是锁屏。
- 10.3 起止装甲、截断/污染检测：已实现；深水掩码/诱饵头：未做（可选扩展）。
- 10.4 双文件多选/拖拽、缺一提示、Vault_ID、指纹：已实现。

### §11 报表
- 双极四列：已实现。
- 时间代币 min：已实现（`60min`；并行账）。
- 增益/阻抑统计：已实现。
- 能量审计（天赋驱动/短板流失/精神暗域）：已实现为列表/条形。
- 雷达图/沙盘：未做（v1.1 是「派生视图」建议，不阻塞 MVP）。
- 链式因果追踪：已实现（`^C_` + 报表链路）。
- 多域合并：已实现。
